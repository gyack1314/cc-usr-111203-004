# 降雨与暴露口径

雨量mm为一天累计非负值，segments为含首末日的声明观测段。段内缺行或null为不完整，不是0。最短段长度按公历日数判断。边界簇只有在观测段内前后分别有至少run_length个连续非超阈值日时才入选；一个已隔开的内部簇不因段边缘的另一个簇被排除而失效。暴露按所有合格完整段日数除365.2425，包含边界观察日。

GPD的参数顺序sigma、xi，xi=0为指数极限。lambda为入选簇数/暴露年数；无入选簇不能拟合GPD。年最大值在z>=0时的CDF为exp(-lambda*S_GPD(z))；给定T>1取目标1-1/T，因此需S=-log(1-1/T)/lambda，若此值>1则对应水平在阈值下，不在尾部适用域。有限支持的上端点不可越过。

domain只检查原雨量和声明段跨度，不做完整性认证、去簇、拟合或重现值。
